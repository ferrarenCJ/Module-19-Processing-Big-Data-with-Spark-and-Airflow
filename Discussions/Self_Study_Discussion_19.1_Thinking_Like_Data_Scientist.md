# Self-Study Discussion 19.1: Thinking Like a Data Scientist – Processing Big Data with Spark and Airflow

One resource that I found particularly helpful during this module was the official Apache Airflow documentation. The documentation provides detailed explanations, installation instructions, DAG examples, operator references, and troubleshooting guidance for workflow orchestration.

**Resource:** Apache Airflow Documentation  
**Link:** https://airflow.apache.org/docs/

This resource helped me understand how Airflow DAGs are structured and how PythonOperator tasks are configured and executed. While completing the Airflow coding activities and final assignment, I frequently referred to the documentation to understand scheduling syntax, DAG parameters, task dependencies, and log monitoring. The examples provided in the documentation made it easier to troubleshoot workflow issues and verify that my DAGs were configured correctly.

Another resource that I found valuable was the official Apache Spark documentation.

**Resource:** Apache Spark Documentation  
**Link:** https://spark.apache.org/docs/latest/

The Spark documentation helped me better understand Spark sessions, DataFrames, and Spark SQL. During the PySpark portion of the module, I used the documentation to review DataFrame methods and SQL query examples. This made it easier to load the `departuredelays.csv` dataset, create temporary views, and run the required SQL queries against the flight data.

One tip I would share with future students is to use Docker Desktop alongside the terminal. Docker Desktop provides a visual way to verify that Spark and Airflow containers are running correctly, while the terminal is useful for executing commands and troubleshooting. Using both tools together made it much easier to complete the hands-on activities and identify issues quickly.

I have bookmarked both the Spark and Airflow documentation sites because they are excellent references that I expect to continue using throughout future data engineering projects and coursework.
