# Question 3

## Which of the following applications performs in-memory processing?

### Options

- Spark ✅
- SQL
- Hive
- MapReduce

### Correct Answer

✅ **Spark**

### Explanation

Spark is designed around **in-memory processing**, which significantly improves performance by reducing the need to continually read and write intermediate results to disk.

Benefits include:

- Faster analytics
- Faster ETL processing
- Reduced I/O overhead
- Improved scalability
