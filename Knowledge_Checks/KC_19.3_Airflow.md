# Question 8

## Suppose your DAG has two Tasks: t1 and t2. What is the correct syntax to schedule t1 prior to t2?

### Correct Answer

✅ **t1 >> t2**

### Explanation

The operator:

```python
>>
```

defines a downstream dependency.

Example:

```python
t1 >> t2
```

Meaning:

```text
Execute t1 first
Execute t2 second
```

# Key Takeaways

- Airflow is an open-source workflow orchestration platform.
- Workflows in Airflow are called DAGs.
- DAGs are written in Python.
- Airflow tasks are created using Operators.
- Dependencies control execution order.
- Airflow provides a web-based UI.
- Airflow supports workflow monitoring and logging.
- Airflow is widely used for ETL and data engineering pipelines.
- Airflow and Spark are frequently used together.
- Airflow manages workflows while Spark performs data processing.

# My Notes

A helpful way to remember the relationship between Airflow and Spark:

```text
Airflow = Orchestration

Spark = Processing
```

Workflow example:

```text
Airflow DAG
      ↓
Launch Spark Job
      ↓
Process Data
      ↓
Load Results
      ↓
Send Notification
```

Airflow controls the workflow, while Spark handles the computational work.
