# Question 3

## Which of the following code can be used along with the spark.read command to enable the inferSchema option?

### Options

- .option("inferSchema","true") ✅
- .enable("inferSchema","true")
- .add("inferSchema","enable")
- .set("inferSchema","true")

### Correct Answer

✅ **.option("inferSchema","true")**

### Explanation

The inferSchema option instructs Spark to automatically determine data types when reading data.

Example:

```python
df = spark.read.format("csv") \
    .option("inferSchema","true") \
    .load(csv_file)
```

Benefits:

- Numeric fields become integers or decimals.
- Dates can be inferred.
- Less manual schema creation.

# Question 4

## Which of the following commands can be used to read a CSV file along with its headers into a DataFrame in Spark?

### Options

- df = spark.read.format("csv").option("header","true").load(csv_file) ✅
- df = spark.read.option("header","true").load(csv_file)
- df = spark.read.format("pdf").option("header","true").load(csv_file)
- df = spark.read.format("csv").load(csv_file)

### Correct Answer

✅ **df = spark.read.format("csv").option("header","true").load(csv_file)**

### Explanation

This command:

- Reads a CSV file
- Uses the first row as column headers
- Loads the data into a Spark DataFrame

Example:

```python
df = spark.read.format("csv") \
    .option("header","true") \
    .load(csv_file)
```

Without:

```python
.option("header","true")
```

the header would be treated as data.

# Question 5

## Suppose you have an SQL query XYZ. How would you execute this query in Spark and display a few rows of the output result?

### Options

- spark.sql("""XYZ""").show(10) ✅
- Sparkquery.execute("XYZ").show(10)
- SparkSql.execute("XYZ").show(10)
- Spark.sql.execute("""XYZ""").show(10)

### Correct Answer

✅ **spark.sql("""XYZ""").show(10)**

### Explanation

Spark SQL queries are executed using:

```python
spark.sql()
```

and results are displayed using:

```python
.show()
```

Example:

```python
spark.sql("""
SELECT *
FROM delays_table
""").show(10)
```

This displays the first ten records returned by the query.

# Question 6

## Which of the following commands can be used to choose only specific columns from a dataset in the DataFrame?

### Options

- df.add("colName1","colName2")
- df.filter("colName1","colName2")
- df.take("colName1","colName2")
- df.select("colName1","colName2") ✅

### Correct Answer

✅ **df.select("colName1","colName2")**

### Explanation

The select() function is used to retrieve only specific columns from a DataFrame.

Example:

```python
df.select(
    "origin",
    "destination"
)
```

Output:

```text
origin
destination
```

This operation improves focus and can reduce processing overhead.
