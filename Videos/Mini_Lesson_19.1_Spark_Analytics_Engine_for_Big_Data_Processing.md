# Overview

Apache Spark is a powerful distributed data processing framework designed for large-scale analytics and big data workloads.

Spark was:

| Year | Milestone |
|--------|--------|
| 2009 | Created at the University of California, Berkeley |
| 2010 | Released as Open Source |
| 2013 | Donated to the Apache Software Foundation |
| 2014 | Became a Top-Level Apache Project |

Today, Spark is one of the most widely used data processing engines across cloud platforms, data lakes, and enterprise data engineering solutions.

# Why Spark Matters

Modern organizations process massive amounts of data generated by:

- Websites
- Mobile applications

- Volume

# Benefits of Spark

## 1. Speed

Spark dramatically reduces data processing times by minimizing expensive disk read and write operations.

### Performance Advantages

- Up to **100x faster than Hadoop MapReduce in memory**
- Up to **10x faster than Hadoop when processing from disk**

### Why It Is Faster

Spark stores intermediate results in memory whenever possible, reducing disk I/O operations.

Benefits include:

- Faster ETL workloads
- Quicker analytics
- Better user experience
- Reduced processing costs

---

## 2. Multi-Language Support

Spark allows developers to work in their preferred programming language.

Supported languages include:

- Python (PySpark)
- Java
- Scala
- SQL
- R

### Why This Is Important

Organizations can:

- Reuse existing skills
- Minimize training
- Integrate with existing applications

---

## 3. Advanced Analytics

Spark extends beyond traditional batch processing.

Built-in capabilities include:

### SQL Analytics

Query datasets using SQL.

### Machine Learning

Build predictive models using MLlib.

### Graph Analytics

Analyze relationship-based data using GraphX.

### Real-Time Streaming

Process live streaming data.

Examples:

- Sensor data
- Financial transactions
- Application logs
- Telemetry feeds

# Example DataFrame Operations

## Create DataFrame

```python
textFile = spark.read.text("SampleFile.txt")
```

---

## Count Rows

```python
textFile.count()
```

Returns:

```text
Total number of rows
```

---

## Display First Row

```python
textFile.first()
```

Returns:

```python
Row(value='...')
```

---

## Filter Rows Containing "Spark"

```python
linesWithSpark = \
    textFile.filter(textFile.value.contains("Spark"))
```

---

## Count Filtered Records

```python
textFile.filter(
    textFile.value.contains("Spark")
).count()
```

---

# SQL Functions in PySpark

Import SQL functions:

```python
from pyspark.sql.functions import *
```

Example:

```python
textFile.select(
    size(
        split(textFile.value, "\s+")
    ).name("numWords")
).agg(
    max(col("numWords"))
).collect()
```

### Purpose

This query:

1. Splits each line into words.
2. Counts the words in each row.
3. Finds the maximum word count.
4. Returns the result.

# Caching

Frequently accessed datasets can be cached in memory.

Example:


- Faster execution
