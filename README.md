# Module 19: Processing Big Data with Spark and Airflow

## Overview

This module introduces two of the most widely used big data workflow engines:

- Apache Spark
- Apache Airflow

Key topics include:

- Big Data Architecture
- Spark Fundamentals
- Docker Containers
- PySpark
- Airflow
- Directed Acyclic Graphs (DAGs)
- Workflow Automation

## Learning Outcomes

By the end of this module, I will be able to:

1. Describe how scalable solutions address challenges of big data.
2. Identify key components of Spark and Airflow.
3. Use Docker to create and manage Spark images and containers.
4. Query data using PySpark.
5. Identify Spark and Airflow use cases.
6. Create workflows using Airflow DAGs.
